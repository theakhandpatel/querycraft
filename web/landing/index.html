01

The contract. Grading by result, never by text.

The claim and the evidence

The result is the answer.

Every exercise says what the answer should look like: these columns, this many rows, this order, these values. If your query returns that, it passes. If it returns the right shape with the wrong numbers, it does not. A query can be tidy and still be wrong. The rows decide.

CheckWhat it means
Columns and orderThe result has the expected columns, in the expected order.
RowsThe right rows, with no extras and none missing.
Row orderWhen the exercise asks for an order, the rows arrive in it.
ValuesEach value matches, with the comparison the exercise declares.

Two different queries can both be right. The app cannot tell them apart, and it does not try.

02

A chapter is a page you can run.

Read, then do

Read a little. Then write.

A chapter gives you a page to read, a query to try, and an exercise or two to do yourself. The example uses the same tables as the exercise, so you are not translating between two fake datasets. The editor sits beside the question. It highlights SQL and suggests table and column names as you type. Run the query, and the rows land underneath. If a check fails, it names the one that failed.

A chapter from SQL Analytics in the Real World.

Sign in. Get your own copy.

Sign in and you get your own copy of the sample database. Insert rows, change a table, open a transaction. Reset puts the original data back. If you are signed out, your queries can read the shared sample but cannot change it.

Your course

Describe the course you want.

Describe the skill you want to build. Querycraft drafts an outline and writes the chapters, but it runs every exercise against the database before you see it. If a reference query fails, the chapter goes back for repair or does not ship. You can edit anything afterward.

Two engines, one grammar

SQLite comes first because the database is a file and needs no server. PostgreSQL comes next, when you want window functions, query plans, and the kind of SQL that shows up in analytics work.

SQLite
select strftime('%Y-%m', ordered_at) as month,
       count(*) as orders
from orders
group by 1
order by 1;
PostgreSQL
select date_trunc('month', ordered_at) as month,
       count(*) as orders
from orders
group by 1
order by 1;
