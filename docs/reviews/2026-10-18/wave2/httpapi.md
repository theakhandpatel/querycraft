# httpapi — wave 2 verification

Scope: production files under `backend/internal/httpapi/`. Tests are evidence only.
Read-only pass: no code changed. `go build ./internal/httpapi/` is green (run 2026-10-18).
`rg` is not installed in this environment, so every cited search ran as
`grep -rn --include='*.go'` across the repo root, excluding `.worktrees/` (stale
worktrees hold older copies and are not consumers of this tree) and `node_modules`.

## Verdict

Most of wave 1 survives. Every citation I re-read matches the live file, and the
five Delete items are each provably dead: no caller, no test, no second shape.
The big Collapse items are directionally right but the proposed remedy is wrong in
three places, because the AI-off refusal has three distinct wire bodies, not one,
and the four list handlers carry a view mapper and a row bound that the proposed
`listSpec` drops. No wave-1 item is outright false, so the final list is 15
confirmed, 5 amended, 1 dropped, 1 new. The highest value is the AI-off family,
which is a ten-site hand-build plus a drifted sentence, and the submit-job pair.
